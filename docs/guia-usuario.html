💾 2. Grabado en USB y Arranque del Sistema

Graba el archivo dzulux-1.1-beta-x86_64.iso en una memoria USB de al menos 4 GB:

  • Ventoy (La opción más recomendada): Instala Ventoy en tu memoria una sola vez. Luego solo copia y pega el archivo ISO dentro de la memoria USB.
  • Rufus (Windows): Selecciona tu USB, elige la imagen ISO de Dzulux y presiona Empezar (en modo ISO o DD).
  • BalenaEtcher (Mac / Windows / Linux): Haz clic en Flash from file, selecciona la ISO, tu USB y presiona Flash!.

Conecta la USB al equipo y enciéndelo presionando la tecla de arranque según la marca de tu equipo:

Marca del Equipo Tecla de Arranque Marca del Equipo Tecla de Arranque
HP / Compaq F9 o Esc Dell / Alienware F12
Lenovo / ThinkPad F12 o Botón Novo Acer / Packard Bell F12 (activar en BIOS)
Asus F8 o Esc Apple Mac (Intel) Mantener presionada Option / Alt

📋 3. Menú de Inicio GRUB: ¿Qué opción elegir?

  • 1. ⚡ Dzulux Linux (Modo Gráfico / Desktop): Inicia el escritorio visual completo basado en XFCE personalizado. Consumo de apenas ~420 MB de RAM. Ideal para uso cotidiano, navegar, programar y jugar.
  • 2. 🖥️ Dzulux Linux (Modo Terminal / Servidor CLI): Inicia en modo consola pura de máxima velocidad (inspirado en Ubuntu Server). Consume solo ~148 MB de RAM. Incluye OpenSSH, UFW, fastfetch y nmtui.
  • 3. 🛡️ Dzulux Linux (Modo Gráficos Seguros - Safe Mode): Activa el parámetro nomodeset. Úsalo si tu computadora tiene tarjetas gráficas problemáticas, pantallas con parpadeo o si estás en una Mac con gráficos híbridos.
  • 4. 🪟 Iniciar Windows Boot Manager (Disco Local): Permite arrancar directamente el Windows que ya tienes en tu disco sin necesidad de retirar la memoria USB.

⚙️ 4. Instalador Guiado y Detección de Silicio (`dzulux-installer`)

¿Para qué sirve?

Instala Dzulux Linux de forma permanente en tu disco duro o unidad de estado sólido, protegiendo tus datos con Dual Boot Real o realizando una instalación limpia.

¿Cómo ejecutarlo?

  • En el Escritorio: Haz doble clic en el acceso directo "Instalar Dzulux Linux".
  • En la Consola: Escribe sudo dzulux-installer y presiona ENTER.

🛡️ Detección Inteligente de Procesador: Edición "Dzulux Lite"

El instalador evalúa el procesador de tu computadora:

  • Si detecta procesadores modestos (Intel Celeron, Pentium, Atom, AMD Athlon ≤ 2 núcleos, o ≤ 3.5 GB RAM): El instalador despliega una alerta de diagnóstico y restringe automáticamente la instalación a Dzulux Lite. Esta edición desactiva de fábrica el compositor de sombras de ventanas de XFWM4 y configura zRAM para evitar congelamientos por saturación de memoria, garantizando una respuesta inmediata a 60 FPS.
  • Si detecta un procesador estándar o potente (Intel Core i3/i5/i7/i9, AMD Ryzen): Desbloquea la versión completa con aceleración visual 3D y efectos translúcidos.

💾 El Salvavidas de las Memorias Soldadas de 32 GB (eMMC)

En laptops de gama de entrada con 32 GB de almacenamiento no extraíble (donde Windows se satura y deja la máquina inutilizable), Dzulux formatea automáticamente usando Btrfs con compresión transparente zstd:1. Esto reduce el espacio del sistema operativo a solo ~3.5 GB, dejándote más de 26 GB libres para tus documentos.

¿Cómo cancelar? Si en cualquier punto antes de confirmar el particionado deseas detenerte, simplemente presiona el botón Cancelar o la tecla ESC; no se tocará ningún archivo de tu disco.

🔄 5. Alternancia entre Entorno Gráfico y Servidor (`switch-mode`)

¿Para qué sirve?

Permite alternar en caliente entre el entorno de escritorio visual y el modo consola pura sin necesidad de reiniciar el equipo.

¿Cómo usarlo?

Comando Efecto Inmediato
switch-mode gui Inicia y abre de inmediato la sesión gráfica XFCE.
switch-mode cli Cierra el entorno gráfico y vuelve a la consola pura de alta velocidad.
switch-mode default gui Configura que el equipo arranque siempre en escritorio gráfico.
switch-mode default cli Configura que el equipo arranque siempre como servidor en terminal.
switch-mode lowspec on/off Activa o desactiva las sombras y efectos para acelerar laptops lentas.
¿Cómo revertir? Si estás en modo terminal y quieres volver al escritorio visual, escribe switch-mode gui.

🎨 6. Gestor de Estilos y Menú Windows 10 (`dzulux-looks`)

¿Para qué sirve?

Transforma por completo el aspecto y la disposición del escritorio en 1 solo clic para adaptarse a tus gustos o para que los usuarios acostumbrados a Windows se sientan como en casa.

¿Cómo usarlo?

Abre el menú de aplicaciones y busca "Dzulux Estilos Visuales" o escribe en la terminal: dzulux-looks.

  • 1. Dzulux Cyberpunk Dark (Predeterminado): Barra superior moderna neón, acentos cian, iconos Papirus y transparencias elegantes.
  • 2. Estilo Windows 10: Mueve la barra de tareas a la parte inferior (40 px), coloca el Menú de Inicio con buscador en tiempo real y categorías organizadas, y vincula la tecla Windows (Super) en tu teclado físico para abrir y cerrar el menú al instante.
  • 3. Modo Minimal Flat: Elimina sombras y transparencias para maximizar la fluidez en laptops antiguas o con gráficos integrados Intel HD.
¿Cómo revertir? Vuelve a ejecutar dzulux-looks y selecciona la opción 1 (*Dzulux Cyberpunk Dark*). El panel regresará a la parte superior y se restaurará la apariencia original.

⚡ 7. Dzulux Performance Engine (`dzulux-performance`)

¿Para qué sirve?

Audita tu procesador y ajusta las frecuencias de reloj, el uso de memoria RAM y la prioridad de las aplicaciones en tiempo real según la tarea que estés realizando.

¿Cómo usarlo?

Ejecuta dzulux-performance o abre "Dzulux Rendimiento y Perfiles" en el menú de aplicaciones.

  • 💼 1. Modo Oficina y Estudio: Optimiza el gobernador de la CPU en modo eficiente (`schedutil`). El sistema responde con rapidez instantánea para abrir documentos y navegar en la web, manteniendo los ventiladores en silencio y temperaturas muy bajas.
  • 🎮 2. Game Booster Puro: Fija las frecuencias del procesador en su rango óptimo constante (evita caídas de reloj o tirones de FPS), purga la memoria caché inactiva de RAM y fuerza el uso de la tarjeta gráfica dedicada en laptops híbridas.
  • 🚀 3. Gamer Sin Límites (Streaming Protegido): Pensado para quienes juegan y transmiten en OBS Studio, Discord o Twitch al mismo tiempo. Asigna prioridad de tiempo real (`renice -10`) a los codificadores de video para que tu transmisión no sufra caídas de cuadros (*dropped frames*).
  • 💤 Congelador de Apps Inactivas (App Sleeper): El modo Sin Límites pone en pausa temporal (`kill -STOP`) programas secundarios de fondo (como suites ofimáticas o navegadores pesados) para entregar el 100% de los núcleos de CPU a tu juego y a tu stream.
¿Cómo revertir? Al terminar tu partida o directo, abre dzulux-performance y elige la opción 1 (*Modo Oficina*). El sistema despierta de inmediato todas las apps pausadas (`kill -CONT`) en el mismo estado exacto donde las dejaste.

🎮 8. Asistente de Controladores al Vuelo (`dzulux-drivers`)

¿Para qué sirve?

Permite que la imagen ISO se mantenga ultra compacta (1.69 GB, respetando el límite estricto de 2 GiB de GitHub) mientras te permite instalar en 1 solo clic los controladores específicos de tu hardware mediante conexión a internet.

¿Cómo usarlo?

  • Conéctate a internet (usa el icono de Wi-Fi en la bandeja o ejecuta nmtui en terminal).
  • Abre "Controladores Adicionales Dzulux" en el menú o escribe dzulux-drivers.
  • El asistente escaneará tus componentes e identificará qué necesita tu equipo:
    • Tarjetas NVIDIA: Descarga controladores propietarios oficiales (`nvidia-open`, `nvidia-utils`, `nvidia-prime`).
    • Intel Graphics: Activa aceleración por hardware VA-API para reproducir video 4K sin usar CPU (`intel-media-driver`).
    • AMD Radeon: Soporte de renderizado Vulkan de alto rendimiento (`vulkan-radeon`).
    • Laptops: Control térmico, gestión de batería TLP y firmware de audio SOF para micrófonos y bocinas internas.
  • Pulsa SÍ y el sistema descargará e instalará los paquetes oficiales.
¿Cómo revertir? Los controladores son paquetes nativos de pacman; puedes desinstalarlos en cualquier momento ejecutando sudo pacman -R <nombre-del-paquete>.

🛡️ 10. Puntos de Restauración Instantáneos (`dzulux-snapshots`)

¿Para qué sirve?

Aprovecha la arquitectura moderna de subvolúmenes **Btrfs** para tomar una captura instantánea de tu sistema en **1 segundo** sin gastar espacio extra. Si instalas un programa que rompe tu sistema o una actualización falla, puedes regresar al estado anterior en segundos.

¿Cómo usarlo?

Lánzalo desde el menú ("Dzulux Snapshots") o escribe en terminal: dzulux-snapshots.

  • 1. Crear Nuevo Punto de Restauración: Toma una captura de seguridad inmediata antes de modificar configuraciones o instalar software.
  • 2. Listar Puntos Existentes: Muestra la lista de capturas con fecha, hora exacta y descripción.
¿Cómo revertir el sistema completo? Si tu sistema no llega al escritorio tras un fallo, reinicia la computadora. En el menú de arranque GRUB, selecciona la entrada "Dzulux Snapshots" y elige la fecha a la que deseas volver. El sistema arrancará exactamente como estaba en ese momento.

🚑 11. Herramienta de Rescate de Archivos, Windows y Discos (`dzulux-rescue`)

¿Para qué sirve?

Convierte a Dzulux Linux en una suite de salvamento forense profesional. Es la herramienta ideal cuando Windows no arranca, se queda en pantalla azul (BSOD), el disco duro tiene sectores dañados, o el usuario olvidó la contraseña de su cuenta local.

🛡️ ¿Por qué Dzulux lo hace más seguro? (El principio de Solo Lectura `ro`)

Cuando un disco duro está fallando o Windows se corrompe, encender la computadora en Windows o montar el disco en modo normal de escritura (rw) activa utilidades destructivas como chkdsk, que frecuentemente eliminan fotos, documentos y carpetas enteras de forma irrecuperable. Dzulux monta la partición en Modo Seguro Solo Lectura (ro), liberando los bloqueos de hibernación rápida de Windows sin alterar un solo byte de tus datos personales, garantizando que el 100% de tus archivos queden protegidos mientras los salvas.

📖 Guía Paso a Paso: ¿Cómo rescatar tus archivos personales?

  1. Paso 1: Arranca tu computadora con la memoria USB de Dzulux Linux y selecciona la opción 1 (Modo Gráfico).
  2. Paso 2: Abre el menú de aplicaciones y haz clic en "Dzulux Rescue" (o abre una terminal y escribe sudo dzulux-rescue).
  3. Paso 3: En el menú interactivo, selecciona la opción 1) "Rescatar Archivos Personales".
  4. Paso 4: El sistema escaneará tus unidades internas (M.2 NVMe, SSD, SATA, eMMC) y te mostrará una lista clara con el tamaño y formato de cada partición. Selecciona con las flechas del teclado la partición donde vive tu Windows o tus documentos.
  5. Paso 5: Dzulux montará la partición en /mnt/windows_rescue y abrirá automáticamente el explorador de archivos Thunar dentro de la carpeta Users/ (donde están todas las cuentas y usuarios del equipo).
  6. Paso 6: Conecta una segunda memoria USB o disco duro externo en cualquier puerto libre de tu PC. Verás que aparece inmediatamente en la barra izquierda de Thunar.
  7. Paso 7: Entra a tu carpeta de usuario en Thunar y simplemente arrastra o copia tus carpetas críticas: Escritorio, Documentos, Descargas, Imágenes, Vídeos y Música hacia tu memoria USB externa.
  8. Paso 8: Al terminar de copiar tus archivos, regresa a la ventana de Dzulux Rescue y pulsa la opción 4) "Desmontar Particiones de Rescate". Esto libera las unidades para que puedas desconectar tus memorias USB con total seguridad sin corrupción de datos.

🔑 Guía Paso a Paso: ¿Cómo quitar o restablecer una contraseña olvidada de Windows?

  1. Inicia Dzulux Rescue y selecciona la opción 2) "Quitar Contraseña Olvidada de Windows".
  2. El asistente escaneará tus discos, localizará la partición con Windows y montará el archivo de base de datos de cuentas Windows/System32/config/SAM.
  3. Se ejecutará la utilidad oficial chntpw, desplegando la lista de todos los usuarios registrados (por ejemplo: Administrator, Alfredo, Familia).
  4. Escribe el nombre o número del usuario que deseas desbloquear y presiona ENTER.
  5. Presiona 1 para borrar la contraseña y dejarla completamente en blanco (sin contraseña).
  6. Si la cuenta muestra la etiqueta [LOCKED], presiona 2 para desbloquear la cuenta.
  7. Presiona q para salir del editor y presiona y cuando te pregunte si deseas escribir los cambios en el disco.
  8. Reinicia el equipo e inicia en Windows: entrarás directamente a tu escritorio sin que te solicite ninguna contraseña.

🩺 Guía Paso a Paso: Auditoría de Salud Física de Discos (S.M.A.R.T.)

Selecciona la opción 3) "Auditoría de Salud Física de Discos". El asistente consultará los sensores de telemetría de tus unidades mediante smartctl:

  • 🟢 PASSED (Salud Perfecta): El disco no tiene sectores dañados y opera dentro de temperaturas normales (30°C a 48°C).
  • ⚠️ Sectores Reasignados (Reallocated Sectors > 0): Significa que la superficie magnética o los bloques flash tienen daño físico. El disco está en riesgo de morir pronto. Se aconseja rescatar los archivos inmediatamente y reemplazar la unidad.
  • 🔴 FAILED: El disco tiene un fallo físico terminal. Debe clonarse o rescatarse antes de que deje de responder por completo.
Desmontaje Seguro: Recuerda siempre seleccionar la opción 4 (Desmontar Particiones de Rescate) antes de apagar la computadora o desconectar tus discos de almacenamiento.

🔋 12. Gestor Inteligente de Batería (`dzulux-battery`)

¿Para qué sirve?

Extiende la duración de la batería de tu laptop adaptándose a la necesidad real del usuario: ahorrar energía sin desconectarte del Wi-Fi cuando necesitas entregar tareas escolares o laborales urgentes.

¿Cómo usarlo?

Abre "Dzulux Ahorro de Batería" en el menú o escribe en terminal: dzulux-battery.

  • 📶 1. Modo Productivo (Wi-Fi 100% Activo): Apaga el Bluetooth (gran consumidor de energía), baja el brillo de pantalla al 40% y activa los perfiles de bajo consumo de TLP, pero mantiene tu Wi-Fi encendido para que puedas navegar y subir tus trabajos escolares.
  • 🚨 2. Modo Emergencia Extrema: Diseñado para cuando te queda 3% de batería y necesitas terminar de escribir un documento offline (apaga todas las antenas y reduce brillo al 15%).
  • ⚙️ 3. Modo Personalizado: Casillas interactivas para que decidas exactamente qué componentes apagar.
¿Cómo revertir? Ejecuta dzulux-battery y selecciona la opción 4 (*Restaurar Modo Normal*). Todas las conexiones, brillo y perfiles de energía se restablecerán al 100%.

🕵️ 13. Escudo de Privacidad en Redes Públicas (`dzulux-stealth`)

¿Para qué sirve?

Protege tu identidad y navegación cuando te conectas al Wi-Fi público de cafeterías, hoteles, bibliotecas o aeropuertos.

¿Cómo usarlo?

Abre "Dzulux Modo Privacidad" o escribe en terminal: dzulux-stealth.

  • 1. Activar Escudo Stealth: Asigna una dirección MAC aleatoria a tu tarjeta Wi-Fi para que no puedan rastrear tu equipo, activa DNS seguro anti-malware (Quad9 9.9.9.9 / Cloudflare 1.1.1.1) y blinda el cortafuegos UFW para rechazar cualquier intento de escaneo de red local.
  • 3. Comprobar Estado: Despliega tu MAC actual, tus servidores DNS y el estado del firewall.
¿Cómo revertir? Ejecuta dzulux-stealth y selecciona la opción 2 (*Desactivar Escudo*). Tu tarjeta de red se reconectará con su dirección MAC física de fábrica y configuración original.

🔄 14. Actualizador del Sistema en Vivo (`dzulux-update`)

¿Para qué sirve?

Permite que cada vez que Alfredo Dzul suba una mejora, corrección o nueva herramienta al repositorio oficial de GitHub, tu computadora pueda descargarla e instalarla directamente sin necesidad de volver a flashear la USB ni reinstalar el sistema.

¿Cómo usarlo?

Abre "Dzulux Actualizador del Sistema" en el menú o escribe en terminal: dzulux-update (o de forma rápida: dzulux-update --quick).

  • 1. Actualizar Suite Dzulux: Descarga al instante las últimas versiones de todos los scripts oficiales, lanzadores del menú y configuraciones maestras directamente desde la rama principal de GitHub.
  • 2. Actualizar Sistema Completo: Sincroniza las herramientas Dzulux y además actualiza todos los paquetes base de Ubuntu/Debian (`apt update && apt upgrade`).
  • 3. Comprobar Versión de ISO: Consulta la API de GitHub Releases y te avisa si hay una nueva versión de ISO lista para descargar a tu carpeta de Descargas.
Seguridad Automática: Antes de aplicar cualquier actualización, dzulux-update crea automáticamente un punto de restauración Btrfs (Snapshot) de seguridad para que siempre puedas revertir el estado si lo deseas.

❓ 15. Solución de Problemas Frecuentes (FAQ)

1. ¿Qué hago si la terminal o una ventana me pide contraseña?

En el entorno Live de Dzulux, el usuario es liveuser y la contraseña es dzulux. También puedes simplemente presionar ENTER (dejar la clave en blanco). Para comandos de administrador ejecuta sudo <comando> y no te pedirá contraseña.

2. ¿Cómo me conecto a una red Wi-Fi si estoy en la terminal CLI?

Simplemente escribe nmtui y presiona ENTER. Se abrirá una interfaz gráfica interactiva en consola donde puedes elegir tu red Wi-Fi e ingresar la contraseña con las flechas del teclado.

3. ¿Qué hago si la pantalla de mi laptop parpadea o se queda en negro al arrancar?

Reinicia tu equipo y en el menú de arranque GRUB selecciona la tercera opción: "🛡️ Dzulux Linux (Modo Gráficos Seguros / Apple Mac & NVIDIA Safe)". Esta opción arranca con controladores genéricos seguros (nomodeset) para permitirte entrar al sistema y descargar los controladores correctos con dzulux-drivers.

4. ¿Cómo actualizo el sistema a los últimos paquetes?

Abre la terminal y escribe sudo apt update && sudo apt upgrade. Al ser una base Ubuntu LTS, recibirás estabilidad total y las versiones más pulidas de tus aplicaciones.
