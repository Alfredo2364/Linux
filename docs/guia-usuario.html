💾 Paso 1: ¿Cómo grabar la imagen ISO en una USB?

Para probar o instalar Dzulux Linux en un equipo físico, necesitas grabar el archivo .iso que viene en este paquete en una memoria USB (de al menos 4 GB):

  • Ventoy (La opción más recomendada): Instala Ventoy en tu memoria USB una sola vez y luego simplemente copia y pega el archivo dzulux-1.1-beta-x86_64.iso dentro de la USB.
  • Rufus (Windows): Abre Rufus, selecciona tu memoria USB, elige el archivo ISO de Dzulux y presiona Empezar (en modo ISO o DD).
  • BalenaEtcher (Windows / Mac / Linux): Selecciona Flash from file, elige la ISO, tu USB y presiona Flash!.

🔄 Paso 2: Menú de Inicio y Modo Dual

Conecta la memoria USB al equipo y enciéndelo presionando la tecla de selección de arranque (F12, F11 o F8 en PC; o manteniendo presionada la tecla Option / Alt en Mac). Verás el menú oficial de Dzulux con las siguientes opciones:

1. Dzulux Linux (Modo Gráfico / Desktop):
Inicia directamente el entorno visual moderno basado en XFCE personalizado con tema oscuro, fuentes estilizadas y wallpapers oficiales. Consumo aproximado de solo 550 MB de RAM.
2. Dzulux Linux (Modo Terminal / Servidor CLI):
Inicia en modo consola pura de alta velocidad, inspirado en la estabilidad y herramientas de Ubuntu Server (incluye OpenSSH, UFW, tmux, fastfetch y nmtui). Consume apenas 150 MB de RAM.
3. Iniciar Windows Boot Manager (Disco Local):
Te permite arrancar directamente el Windows o sistema que ya tienes instalado en tu disco duro si necesitas usarlo sin desconectar la USB.

⚙️ Paso 3: Instalación con Soporte Dual Boot

Para instalar Dzulux en tu disco duro, solo abre el acceso directo en el escritorio o escribe en la terminal:

sudo dzulux-installer

El instalador es completamente interactivo y te preguntará cómo deseas configurarlo:

  • Modo Dual Boot (Recomendado si ya tienes Windows o Mac): Mantiene intacto tu sistema operativo original. Dzulux se instalará en una partición dedicada compartiendo la partición EFI de arranque. Al reiniciar, podrás elegir cada vez si quieres entrar a Dzulux o a Windows/Mac.
  • Modo Limpio: Reemplaza todo el disco para uso exclusivo de Dzulux Linux.

📋 Resumen de Comandos Rápidos

Comando ¿Para qué sirve?
dzulux-installer Inicia el instalador interactivo paso a paso.
switch-mode gui Inicia el entorno de escritorio gráfico XFCE.
switch-mode cli Regresa a la terminal / consola pura.
nmtui Configura y conecta redes Wi-Fi mediante interfaz visual en consola.
hw-detect Muestra el diagnóstico de tus tarjetas gráficas, audio y batería.
fastfetch Despliega el resumen de componentes y la firma de Alfredo Dzul.
