Concepto Dual Único

Elige en cada encendido si quieres iniciar en Modo Gráfico (XFCE ligero y moderno) o en Modo Terminal (servidor de alto rendimiento). Puedes alternar entre ambos al vuelo con el comando switch-mode.

🪟

Soporte Dual Boot

¿Tienes Windows o macOS en tu computadora? Dzulux no lo borra. Su instalador guiado configura el menú de inicio para que elijas entre Windows y Dzulux cada vez que prendas el equipo.

🎮

Controladores Out-of-the-Box

Drivers completos para tarjetas Intel, AMD Radeon y NVIDIA (DKMS con Prime para laptops). Además de soporte para Wi-Fi Broadcom en computadoras Apple Mac.

🔋

Optimizado para Laptops

Gestión avanzada de batería con TLP, control de brillo nativo con brightnessctl y audio moderno PipeWire con firmware SOF para altavoces y micrófonos de última generación.

🖥️

Terminal Estilo Ubuntu Server

Para tus proyectos, servidores, Docker o Tailscale. Incluye OpenSSH, cortafuegos UFW, tmux y configuración de red visual con nmtui sin consumir más de 150 MB de RAM.

📋

Instalador Amigable

Con dzulux-installer no necesitas comandos difíciles. El asistente en español te va explicando con claridad cada opción antes de hacer cualquier cambio.
